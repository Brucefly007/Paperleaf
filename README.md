# 纸间 · Paperleaf

一款本地运行的轻量图文阅读器、编辑器。用来写文字、粘贴图片，再把这份文档交给人或 AI 阅读。

当前版本：**1.2.0**。新增 **Ctrl+H 查找替换**，支持上一处、下一处、替换当前一处和全部替换；替换为留空时删除匹配文字。全部替换可以按 Ctrl+Z 一次撤销，图片及未匹配文字的格式会保留。

文字颜色：选中文字后点击工具栏“颜色”，选择预设颜色或“更多颜色”自定义；不选文字时，可设置接下来输入的颜色。颜色支持撤销、重做，保存在 HTML 中。

已修正查找跨图片误匹配、代码块首尾空行丢失、局部取消粗体或斜体后保存失效等问题；剪贴板重试时会检查光标位置，避免内容粘贴到移动后的光标处。小窗口下工具栏自动换行，最近文档可以滚动，底部状态过长会省略显示。

保留此前的微信、QQ 图片粘贴兼容：优先读取 PNG，兼容 DIB / DIBV5 和 GDI 位图，修正旧式位图全零透明通道，并支持不同 RGB 通道掩码。真正的 PNG 透明效果会保留；粘贴失败不会删除已选内容。

## 开始使用

直接双击 **`dist/Paperleaf.exe`**。只需复制这个 EXE 即可带走软件，不需要安装器、Node.js、Python、浏览器组件或额外 DLL。

运行环境为 **Windows 10 / 11 + .NET Framework 4.8**，通常已随 Windows 提供。这个单文件程序使用系统的 .NET Framework，不包含一整套运行时；如果系统移除了该组件，需要先恢复它。

`examples/欢迎使用.html` 是一份已经嵌入图片的示例。可以在软件中打开，也可以用浏览器直接阅读。

## 能做什么

- 文字输入、选择、复制粘贴、撤销和重做。
- 标题 1 / 2 / 3、加粗、斜体、文字颜色、项目列表。
- 粘贴截图或剪贴板图片，插入图片文件，拖入多张图片。
- 图片直接嵌入文档；右键图片可以编辑说明或复制图片。
- 阅读模式、专注模式、查找替换、字数与图片统计、最近打开的文档。
- 打开纸间 HTML，导入 Markdown、UTF-8 TXT。
- 导出 Markdown 和图片，也可单独导出纯文本。
- 有修改时每 12 秒保存一份本地恢复草稿；异常关闭后，下次启动会询问是否恢复。
- 保存采用先写临时文件、再替换原文件的方式。关闭有未保存修改的文档时会询问。

## 两种保存方式

| 用途 | 结果 | 如何移动或分享 |
| --- | --- | --- |
| 日常保存：保存 / Ctrl+S | 一个 `.html` 文件，正文和图片全部内嵌 | 只需带走这个 HTML |
| 交给 AI：导出给 AI | 一个 `.md` 文件和同名 `.assets` 图片文件夹 | 两者一起提供，保持相对位置 |

HTML 内是标准的正文、标题、列表、图片说明和 Base64 图片，没有应用专属的加密或二进制文档容器。浏览器可以直接显示，无需运行纸间。

文字颜色由 HTML 保留。Markdown / TXT 导出不保留文字颜色；需要保留彩色排版时，请使用“保存”生成的 HTML。

AI 通常可以读取 HTML 或 Markdown 的文字。要让 AI 理解图片，建议导出 Markdown，并在所用 AI 平台中同时提供图片；具体能否识图取决于该平台是否支持图片输入或文件读取。软件中的“导出给 AI”只写入本地文件，不会调用模型或上传文件。

导出不会覆盖当前正在编辑的 HTML，也不会清除“未保存修改”状态。请用“保存”保存原文档。

## 常用操作

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 | Ctrl+N / Ctrl+O |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |
| 插入图片 | Ctrl+Shift+I |
| 导出给 AI | Ctrl+Shift+E |
| 加粗 / 斜体 | Ctrl+B / Ctrl+I |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 查找 / 替换 | Ctrl+F / Ctrl+H |
| 下一处 / 上一处 | F3 / Shift+F3 |
| 阅读模式 | Ctrl+Shift+R |
| 专注模式 | F11 |
| 关闭查找或退出专注 | Esc |

也可以把 HTML、Markdown 或 TXT 文件拖进窗口，或把文件拖到 EXE 上打开。

## 查找与替换

按 **Ctrl+H**，输入“查找”和“替换为”的文字。用“上一处 / 下一处”选中要修改的位置，再点“替换此处”；替换后会自动定位下一处。也可以点击“全部替换”，处理整篇文档并显示替换数量。按 Esc 关闭面板。

尚未定位匹配、查找文字被修改或手动移动选区后，点击“替换此处”会先定位，第二次点击才替换，便于确认目标。查找框中 Enter 为下一处，Shift+Enter 为上一处；替换框中 Enter 为替换此处。

查找按普通文字匹配，**不区分英文大小写**，不使用正则表达式。替换为留空表示删除。全部替换只处理操作开始时的非重叠匹配，新插入的文字不会重复参与本次替换。Ctrl+Z 一次撤销整批替换，Ctrl+Y 可重做。跨不同颜色或粗斜体的匹配，替换文字沿用首字符的格式。

阅读模式允许查找前后定位，替换功能在返回编辑后可用。图片是查找边界，替换不会跨图片匹配或修改图片说明。

## 格式和边界

- 默认保存为 HTML；Markdown、TXT 是导入格式。导入后按 Ctrl+S 会创建 HTML，原文件不会被自动修改。
- Markdown 支持常见标题、加粗、斜体、链接、列表、引用、行内代码、代码块和本地相对路径图片。复杂表格、公式、任务列表、完整 CommonMark 语法及任意网页排版暂不支持。未知语法通常保留为文字。
- HTML 打开功能针对纸间生成的 HTML，不是任意网页导入器；不会执行脚本、加载外部网页、访问外部图片。
- Markdown 的图片需要位于该 Markdown 所在目录或子目录。网络图片、越过目录的图片或找不到的图片保留原始引用文字，不会自动下载。
- 粘贴网页或 Word 内容时，文字按纯文本插入；整段网页连同其远程图片的富文本粘贴暂不支持。图片可以单独复制后粘贴，或先保存到本机再插入。
- 支持 PNG、JPEG、BMP、GIF、TIFF 静态图片；GIF / 多页图片按首帧插入。保存时统一内嵌为 PNG，照片文件可能因此变大。
- 单图上限为 25 MB、6400 万像素；保存后的完整文档上限为 120 MB。不支持图片裁剪、绘图或自由拖拽排版。
- “字数”是非空白字符数，包含英文字符和标点。
- 不包括云同步、多人协作或内置 AI 聊天。

最近文件列表与恢复草稿保存在 `%LOCALAPPDATA%\Paperleaf`。这表示 EXE 可以单独分发，但它不是“绝不写用户目录”的便携模式。正常保存或明确放弃修改后，会清理当前会话的恢复草稿。自动草稿只用于意外退出恢复，不代替手动保存；最近 12 秒内的修改可能尚未备份。

## 源码与编译

语言：**C#**。界面：**WPF**。无第三方运行时依赖或 NuGet 包。

```text
Paperleaf/
  dist/Paperleaf.exe            可直接运行的单文件软件
  dist/self-test-result.txt     最近一次自动检查结果
  dist/interface-preview.png   自动渲染的界面预览
  dist/interface-minimum-preview.png  最小窗口界面预览
  dist/replace-preview.png     查找替换面板的最小窗口预览
  examples/欢迎使用.html         单文件图文示例
  src/                         完整 C# / XAML 源码和图标
  build.ps1                    一键编译
  README.md                    本说明
```

在 PowerShell 中进入本文件夹，运行：

```powershell
.\build.ps1
```

编译并运行自动检查：

```powershell
.\build.ps1 -Test
```

编译脚本使用 Windows 的 .NET Framework C# 编译器，输出 AnyCPU 的 Windows 图形程序。XAML 和图标都嵌入 EXE；应用代码不联网。

自动检查覆盖 Ctrl+H 的命令绑定和替换面板、双向定位、单处及全部替换、空替换、相邻匹配、批量撤销重做、颜色和图片保留；也覆盖颜色按钮操作、格式存取、代码块空行、最小窗口布局及 PNG / DIB / DIBV5 / GDI 剪贴板兼容；测试只使用自造数据，不读取或覆盖你的真实剪贴板。当前环境缺少 computer-use 桌面组件，尚未完成真实微信 / QQ 复制图片或系统自定义颜色对话框的桌面交互实测。
